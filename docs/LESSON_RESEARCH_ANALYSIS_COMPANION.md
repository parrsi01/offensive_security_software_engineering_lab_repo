# Lesson Research & Analysis Companion

Author: Simon Parris  
Date: 2026-02-26

Use this companion to translate each lab into interview-quality reasoning and secure engineering takeaways.

## Analysis Framework

For each lab, capture:

1. Vulnerability class
2. Preconditions
3. Observable impact
4. Root cause mechanism
5. Mitigation / secure coding pattern
6. Verification strategy
7. Operational safety constraints

## Interview Translation Prompts

- How would you explain this vulnerability to a software team?
- What is the smallest safe reproduction?
- How would you verify the remediation in CI?
- What guardrail would prevent regression?

## Portfolio Extraction Ideas

- secure remediation diffs
- lab execution notes with evidence
- vulnerability class summaries
- test/verification snippets

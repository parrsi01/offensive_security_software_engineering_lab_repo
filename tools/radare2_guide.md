# Radare2 Guide (Intro)

## Basic Commands
- Open: `r2 ./binary`
- Analyze: `aaa`
- List functions: `afl`
- Print disassembly: `pdf @ sym.main`
- Strings: `iz`
- Seek: `s <addr>`
- Hex dump: `px 64`
- Quit: `q`

Use radare2 as a secondary disassembler after understanding the program with source and objdump in this course.

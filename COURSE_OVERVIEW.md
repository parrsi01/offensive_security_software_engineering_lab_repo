# Course Overview

Author: Simon Parris  
Generated: 2026-02-24

## Objective
Develop practical offensive security software engineering skills in a controlled environment by combining vulnerability analysis, debugging, reverse engineering, fuzzing, secure coding, and documentation.

## Learning Outcomes
- Explain memory safety failures and common mitigations (ASLR, NX/DEP, RELRO, stack canaries).
- Reproduce intentionally vulnerable behavior in C and Python applications.
- Use debugger and disassembly tools to inspect program state.
- Build basic fuzzing automation and crash triage workflows.
- Identify insecure patterns in code with a lightweight static scanner.
- Implement secure remediations and validate with tests.
- Produce a professional vulnerability report with risk, impact, and patch guidance.
